# Telegram LLM Analytics Bot

Мини-продукт для аналитики текстовых данных с помощью LLM.  
Пользователь может отправлять файлы CSV/Excel или текстовые сообщения, бот генерирует краткое резюме и ключевые идеи.

## ⚡ Возможности
- Приём текстовых сообщений и CSV/Excel-файлов
- Автоматическая генерация кратких саммари
- Выделение ключевых идей
- Работа через Telegram
- Деплой через Docker

## 🛠 Технологии
- Python 3.11+
- [aiogram](https://docs.aiogram.dev/en/latest/) — Telegram Bot API
- LLM через [Groq API](https://console.groq.com/home)
- Docker
